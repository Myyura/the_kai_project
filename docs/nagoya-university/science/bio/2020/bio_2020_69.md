# 名古屋大学 理学研究科 理学専攻 生命理学領域 2020年度 [69]

## **Author**

祭音Myyura (co-authored with GPT 5.6 SOL)

## **Description**

題意の要約。
実験動物60匹を独立な2群に分け、対照食と試験食を与えて、正規分布しないパラメータ $A$ を比較する。
適切な検定の組を選べ。

1. ノンパラメトリック検定・$t$ 検定
2. ノンパラメトリック検定・Mann--Whitney の $U$ 検定
3. パラメトリック検定・$t$ 検定
4. パラメトリック検定・Mann--Whitney の $U$ 検定
5. パラメトリック検定・Kolmogorov--Smirnov 検定

## **Kai**
この選択肢の中で、独立2群を比較するノンパラメトリック検定との組み合わせが正しいのは Mann--Whitney の $U$ 検定である。順位を用い、母集団の正規性を前提としない。
