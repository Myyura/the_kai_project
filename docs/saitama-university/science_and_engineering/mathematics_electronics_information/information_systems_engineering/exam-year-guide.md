# 埼玉大学 入試年度・実施時期の対応について

## **Author**
[思齐塾](https://www.siqishu.com/), 祭音Myyura

## この文書について

このページは試験問題ではなく、過去問の年度と実施時期を整理するための資料です。入学年度と試験実施年は一致しない場合があり、秋期入学試験もあります。ファイルの番号や資料の並び順だけから実施年月を推定しないでください。

## 原始编排说明（保存原文）

以下保留原文档的说明内容。这段文字是资料编排备注，并非学校官方的考试日期证明；其中“夏、冬”的概括不能代替逐份原卷与官网索引的核对。

年份区分告示：标签名都为H30-1,H30-3,R02-1,R02-3数字排序依次为夏 冬，以及2021年为特殊有3套卷子，排序为 夏 冬 以及 特别备注

### 题目描述

本文件不是试题。原始 Description 仅提供年份与卷次的区分说明：标签名包括 `H30-1`、`H30-3`、`R02-1`、`R02-3`，各年份内按数字顺序依次对应夏季卷、冬季卷；2021 年情况特殊，共有三套资料，顺序依次为夏季卷、冬季卷和特别备注。

除此之外，原始 Description 未给出任何题目、条件、公式或小问，Kai 也仅标记为 `N/A`。因此无法从现有信息唯一恢复具体试题内容，本条目只保留上述资料编排说明。
