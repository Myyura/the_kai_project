# 埼玉大学 入試年度・実施時期の対応について

## **Author**
[思齐塾](https://www.siqishu.com/), 祭音Myyura

## この文書について

このページは試験問題ではなく、過去問の年度と実施時期を整理するための資料です。入学年度と試験実施年は一致しない場合があり、秋期入学試験もあります。ファイルの番号や資料の並び順だけから実施年月を推定しないでください。

## 実施年月と入学時期

公式 PDF の識別番号と実施年月、入学時期の対応を示す。

| 公式 PDF | 実施年月 | 原卷表紙の入学時期 |
| --- | --- | --- |
| R02-1 | 2019年8月 | 2020年4月・2019年秋期 |
| R02-3 | 2020年2月 | 2020年4月 |
| R03-1 | 2020年8月 | 2021年4月・2020年秋期 |
| R03-3 | 2021年2月 | 2021年4月 |
| R03-4 | 2021年8月 | 2021年秋期 |
| R04-1 | 2021年9月 | 2022年4月 |
| R04-2 | 2022年2月 | 2022年4月 |

R03-4 は秋期入学試験、R04-1 は翌年4月入学の試験である。

出典：[大学の過去問一覧](https://www.ics.saitama-u.ac.jp/exam/in/admissions-prepare/)、[大学一覧ページの2021年5月の保存版](https://web.archive.org/web/20210517100644/http://www.ics.saitama-u.ac.jp/exam/in/admissions-prepare/)、[大学一覧ページの2025年9月の保存版](https://web.archive.org/web/20250924105239/https://www.ics.saitama-u.ac.jp/exam/in/admissions-prepare/)。

### 题目描述

年份与卷次的区分如下：标签名包括 `H30-1`、`H30-3`、`R02-1`、`R02-3`，各年份内按数字顺序依次对应夏季卷、冬季卷；2021 年情况特殊，共有三套资料，顺序依次为夏季卷、冬季卷和特别备注。
