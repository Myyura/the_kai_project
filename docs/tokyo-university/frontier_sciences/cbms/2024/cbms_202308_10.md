## **Description**

Given $\mathbf{V}$, an integer array of $N$ elements, the following procedure, `quick_sort` sorts the entire array of $\mathbf{V}$ by calling `quick_sort(0, V, 0, N - 1, -\infty, +\infty)`. `swap(x, y)` is a special procedure that swaps the values of $x$ and $y$.

```python
def quick_sort(d, V, li, hi, lv, hv):
    if hi <= li: return
    p = li; l = li + 1; h = hi

    # (A) begins
    while l < h:
        while l <= hi and V[l] < V[p]: l += 1 # (B): V[l] < V[p]
        while li <= h and V[p] <= V[h]: h -= 1 # (C): V[p] <= V[h]
        if h <= l: break
        swap(V[l], V[h])
        l += 1; h -= 1
    swap(V[p], V[h])
    ## (A) ends
    
    if lv < V[h]: quick_sort(d + 1, V, li, l - 1, lv, V[h])
    if V[h] < hv: quick_sort(d + 1, V, h + 1, hi, V[h], hv)
```

(1) Answer what (A) does over array $\mathbf{V}$.

(2) Answer what $d$ holds.

(3) Let $d_{\max}$ be the maximum $d$ during the entire sorting procedure. Given $N$, show an example of array $\mathbf{V}$ which gives the largest possible $d_{\max}$.

(4) Explain what $lv$ and $hv$ hold.

(5) We modify the program so as to work as is when $d$ is even and as if we swap inequality symbols $(B)$ and $(C)$ when $d$ is odd. Explain what happens if we sort the $\mathbf{V}$ you answered in (3).

(6) Explain the benefits of introducing the modification explained in (5).

### 解题思路

这个问题涉及到快速排序算法的深入分析。我们需要理解算法的每个部分，包括分区过程、递归深度、边界条件等。同时，我们还需要分析算法的最坏情况和一个有趣的变体。解答将涉及算法分析、最坏情况构造和算法优化等方面。

### 1. Analysis of section (A)

Section (A) is intended to be the partitioning step of quicksort. It should perform the following operations on array $\mathbf{V}$:

a) It chooses the first element $V[p]$ as the pivot.

b) It partitions the array such that all elements less than the pivot are moved to the left side, and all elements greater than or equal to the pivot are moved to the right side.

c) Finally, it places the pivot in its correct sorted position.

After a valid partition, the pivot is in its final sorted position, with smaller elements to its left and larger or equal elements to its right. For the given routine, $[1,2]$ skips the loop and becomes $[2,1]$. On $[0,1,2]$, scan (C) reaches $h=-1$; with Python indexing, subsequent calls can repeat the entire interval indefinitely. Thus these partition properties do not hold for every input.

### 2. The meaning of $d$

$d$ represents the recursion depth of the quicksort algorithm. It starts from 0 and increases by 1 with each recursive call. This parameter can be used to track the depth of the recursion tree or to implement optimizations based on the recursion depth.

### 3. Worst-case scenario for $d_{\max}$

For the printed procedure there is no largest finite $d_{\max}$. With $\mathbf V=[0,1,2]$, Python semantics alternate the full interval between $[0,1,2]$ and $[2,1,0]$, so $d$ increases without bound. Thus question (3) has no finite answer unless the partition code is corrected. For the implementation below, an all-equal array gives $d_{\max}=N-1$ when alternation is disabled. Each call removes one pivot, so this is the maximum possible depth.

### 4. The roles of $lv$ and $hv$

$lv$ and $hv$ are used to optimize the quicksort algorithm by avoiding unnecessary recursive calls:

- $lv$ is the lower value bound inherited by the current subarray.
- $hv$ is the upper value bound inherited by the current subarray.

In the intended partition, values lie between $lv$ and $hv$. After choosing pivot value $V[h]$, a left call is unnecessary when $V[h]=lv$, and a right call is unnecessary when $V[h]=hv$; this is what the two strict tests express.

### 5. Effect of swapping (B) and (C)

Swapping the inequality symbols exchanges only the treatment of keys equal to the pivot: at even depths they go to the right side, and at odd depths they go to the left side. It does not reverse the sort order. For the distinct-key counterexample $[0,1,2]$ from (3), the comparisons are unchanged, so the printed procedure still does not terminate.

### 6. Benefit of the modification

In the implementation below, alternating the side receiving equal keys allows the inherited value bounds to stop duplicate blocks. For an all-equal array with $N\ge3$, the first partition sends the remaining keys right, and the next sends them left; the lower bound then equals the pivot and stops that branch. Thus the maximum depth is 2 and the work is $O(N)$, instead of depth $N-1$ and $\Theta(N^2)$ work without alternation. Distinct monotone arrays still give one-sided recursion.

### Partition implementation

```python
def quick_sort_bounded(V, alternate=False):
    max_depth = 0

    def visit(d, li, hi, lv, hv):
        nonlocal max_depth
        max_depth = max(max_depth, d)
        if hi <= li:
            return
        pivot = V[li]
        l, h = li + 1, hi
        equal_left = alternate and d % 2 == 1
        while l <= h:
            while l <= h and (V[l] <= pivot if equal_left else V[l] < pivot):
                l += 1
            while l <= h and (pivot < V[h] if equal_left else pivot <= V[h]):
                h -= 1
            if l < h:
                V[l], V[h] = V[h], V[l]
                l += 1
                h -= 1
        V[li], V[h] = V[h], V[li]
        if lv < pivot:
            visit(d + 1, li, h - 1, lv, pivot)
        if pivot < hv:
            visit(d + 1, h + 1, hi, pivot, hv)

    visit(0, 0, len(V) - 1, -float('inf'), float('inf'))
    return max_depth
```
