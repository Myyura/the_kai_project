## **Description**

B. 以下の (1)～(10) の問いに答えなさい。

(1) $10^9$ の配列における任意の位置を表すには，何バイト必要か。

A. 2　B. 4　C. 8　D. 16

(2) 記憶媒体のアクセス速度を速い順に並べよ。

A. CPU レジスタ > CPU キャッシュメモリ > 主記憶 > ディスク

B. 主記憶 > ディスク > CPU レジスタ > CPU キャッシュメモリ

C. CPU キャッシュメモリ > CPU レジスタ > ディスク > 主記憶

D. CPU キャッシュメモリ > 主記憶 > ディスク > CPU レジスタ

(3) 対応のない2標本間の平均値の差を調べる検定として最も適切なものを以下の選択肢から選べ。

A. スチューデントの t 検定

B. カイ二乗検定

C. 二項検定

D. 多重検定

(4) 変量 $x$ と $y$ のピアソン相関係数 $r_{xy}$ を共分散 $\sigma_{xy}$，$x$ の標準偏差 $\sigma_x$，および，$y$ の標準偏差 $\sigma_y$ を使って表せ。

(5) 統計的仮説検定において「帰無仮説」とは何か説明せよ。

(6) カレントディレクトリにあるディレクトリとファイルの一覧を表示させる UNIX コマンドを答えよ。

(7) 公開鍵暗号方式を用いてファイルを暗号化して送信するとき，ファイルの受信者がファイルの復号に用いるのに最も適切な鍵はどれか？

A. 送信者の秘密鍵

B. 送信者の共通鍵

C. 受信者の秘密鍵

D. 受信者の公開鍵

(8) 10種の文字を使い3桁のログインパスワードを設定した。悪意のある他者がランダムなパスワードを繰り返し入力するとき，5回以内の試行でログインできる確率を以下より選べ。

A. $\displaystyle\left(1-\frac1{1000}\right)^5$

B. $\displaystyle1-\left(1-\frac1{1000}\right)^5$

C. $\displaystyle\frac{1-(1/1000)^5}{1-1/1000}$

D. $\displaystyle\frac{1-(1-1/1000)^5}{1-(1-1/1000)}$

(9) 表計算ソフトで以下のような表を作成した。B5, C5, D2, D3, D4, D5 に入力するべき式を答えよ。

| | A | B | C | D |

| 1 | 氏名 | 第一回 | 第二回 | 合計 |
| 2 | Alice | 60 | 90 | |
| 3 | Bob | 30 | 80 | |
| 4 | Chris | 76 | 70 | |
| 5 | 平均値 | | | |

(10) 臨床検査において次のような表を得た。感度が 0.8 のとき，$A$ の値を求めよ。

| 検査結果 | 真の状態：陽性 | 真の状態：陰性 |
|---|---:|---:|
| 陽性 | $A$ | 10 |
| 陰性 | 20 | 190 |
