# 東京大学 経済学研究科 マネジメント専攻 2019年9月実施 修士課程入学試験 設問1

## **Author**

祭音Myyura (co-authored with GPT 6 Astra)

## **Description**

1980年代の半ば、アメリカの経営学では、工場などでの労務管理(personnel management)を人的資源管理(Human Resource Management)と呼ぼう、との流れがあり、実際、この時期以降、HRMという言い方が米国その他の国で定着した。その中で重要な論文の一つはR.E. Walton(1985)の “From Control to Commitment”である。Waltonらは、米国の製造大企業の工場の人事労務管理は、それまで伝統的に採られてきたとされる「コントロール・モデル」から、当時で言えば比較的新しかった「コミットメント・モデル」の重視へと移行すべきだと主張した。ここで示された「コントロール・モデル」と「コミットメント・モデル」は、必ずしも厳密な実証分析には基づかない二つの「理念型 (ideal types)」だが、これらを要約して比較したものが表1である。当時、コントロール・モデルはGM(General Motors)など米国製造系大企業の伝統的ブルーカラー労務管理、コミットメント・モデルはトヨタなど一部の日本の製造大企業のそれを念頭に置いていたと言われていた。

その後、1990年代に入ると、日本のマクロ経済は長期の低成長に陥り、また家電・エレクトロニクス・半導体などの領域で日本産業は停滞・衰退した。その一方で、冷戦終結後のアメリカ経済は、インターネット出現後のICT産業や金融業の発展をベースに着実に成長し、特に米国西部のシリコンバレー地域はデジタル情報産業の中心地として発展したが、GMなど米国系自動車メーカーの一部は経営危機に陥った。一方、中国などアジア系の新興国経済も多くが急成長した。そうした中で、もともとは日本企業の慣行の影響が強かったHRMという考え方、あるいはコミットメント・モデルと整合性の高いトヨタ的な生産方式(例えばリーン生産方式)は、2010年代になっても欧米やアジア等の実務家の間で人気と影響力を維持している。

| 雇用保障・訓練 | レイオフにより、人件費を変動費化<br />訓練の軽視(単能工) | レイオフをできるだけ回避する努力<br />訓練の重視(多能工) |
| 労使関係・コミュニケーション | 狭い範囲での労使コミュニケーション<br />苦情制度、団体交渉を通じた情報伝達<br />敵対的な労使関係(adversarial) | 広範な従業員参加制度<br />会社のデータに関する労使の情報共有<br />労使共同での問題解決 |

### 题目描述

20世纪80年代中期，美国经营学界出现了将工厂等场所的劳务管理（personnel management）称为人力资源管理（Human Resource Management）的潮流。实际上，此后HRM这一说法在美国及其他国家逐渐普及。其中一篇重要论文是R. E. Walton于1985年发表的“From Control to Commitment”。Walton等人主张，美国大型制造企业工厂的人事劳务管理，应从被认为长期沿用的“控制模式”，转向重视当时较新的“承诺模式”。这里提出的“控制模式”和“承诺模式”，是未必建立在严格实证分析基础上的两种“理想类型”（ideal types）；表1对二者作了概括比较。据称，当时控制模式所着眼的是通用汽车（GM，General Motors）等美国大型制造企业传统的蓝领劳务管理，而承诺模式所着眼的是丰田等部分日本大型制造企业的相应做法。

此后，进入20世纪90年代，日本宏观经济陷入长期低增长，家电、电子、半导体等领域的日本产业也出现停滞和衰退。另一方面，冷战结束后的美国经济以互联网出现后的ICT产业和金融业发展为基础稳步增长，尤其是美国西部的硅谷地区发展成为数字信息产业的中心，但通用汽车等部分美国汽车制造商却陷入经营危机。同时，中国等许多亚洲新兴国家的经济也实现了高速增长。在这一背景下，原本深受日本企业惯例影响的HRM理念，以及与承诺模式具有较高一致性的丰田式生产方式（例如精益生产方式），到了2010年代仍在欧美和亚洲等地的实务界保持着广泛影响。

|  | 控制模式 | 承诺模式 |
| --- | --- | --- |
| 工作设计 | 工作细分、技能解体（deskilling）<br />只参与自己分担的工作<br />计划（专业技术人员）与执行（作业人员）分离，工作固定化 | 宽泛界定工作范围、培养多能工（multi-skilled）<br />以团队形式共同负责整个系统的改善<br />计划与执行整合（作业人员与技术人员共同工作）<br />根据情况灵活改变工作分配 |

| 管理组织 | 自上而下，管理层级较多<br />依靠规则和程序进行控制<br />依据正式权限行使权力<br />强调各种地位象征 | 扁平化，管理层级较少<br />共享价值观和目标<br />依据专业能力（expertise）行使权力<br />消除地位象征，趋向平等 |
| 薪酬体系 | 只有个人报酬体系<br />职务工资（以岗位评价为基础） | 并用集体报酬和团队激励<br />职能工资（以技能为基础） |

| 劳资关系与沟通 | 劳资沟通范围狭窄<br />通过申诉制度、集体谈判传递信息<br />对抗性的劳资关系（adversarial） | 广泛的员工参与制度<br />劳资双方共享公司数据<br />劳资共同解决问题 |
| 经营理念 | 强调经营管理权，重视对股东的责任 | 考虑多种利益相关者 |

## **Kai**

### 小問1

Waltonらの主張は、従業員を監督の対象としてのみ扱うよりも、その能力と自発的な協力を引き出す方が、品質、生産性、柔軟性を高められるという考えに基づく。ここでコミットメントとは、単に会社に長く在籍することではなく、組織の目標を受け入れ、その実現に主体的に貢献する姿勢である。

コントロール・モデルでは、仕事を細分化し、管理者が計画、作業者が実行を担う。これは標準化された大量生産を管理しやすくする一方、作業者が自分の担当範囲を超えて改善に参加する余地を狭める。細かな指示と監督だけでは、現場の暗黙知や、指示されていない問題への対応を十分に引き出せない。

これに対して、仕事の裁量と改善への参加機会を広げれば、自分の工夫が成果につながるという実感を得やすくなり、意欲が高まる。また、訓練と職務の拡大による多能工化は、欠員や需要変動への対応、工程間の助け合いを可能にする。したがって、意欲の向上と能力の向上が、問題解決への参加機会を通じて競争成果につながる。

その効果には、施策間の整合性が必要である。例えば、改善による省力化が直ちに自分の解雇につながるなら、従業員は改善に協力しにくい。雇用の安定に努め、技能形成を支援し、共同成果を報酬に反映することで、改善への協力が本人にも利益をもたらすようにする。参加制度だけを導入するのではなく、仕事、訓練、評価、報酬、雇用方針を相互に補完させることが重要となる。

歴史的には、1970～80年代の国際競争の激化、とりわけ自動車などでの日本企業の台頭が、米国の大量生産と労使関係を再検討する契機となった。現場の技能、チームでの改善、労使協力が競争力の源泉になり得るという認識は、従業員重視を生産上の合理性と結びつけた。Waltonらは、この自発的協力を引き出す仕組みに業界を超えた意義を認めたのである。ただし、それが全産業で常に優れるかは、別途検討すべき問題である。

### 小問2

コミットメントを重視する考えは1990年代以降にも意義を持つが、すべての職場が同一の制度へ移行すべきだとする主張は強すぎる。

まず、題文にある日本経済の停滞と米国ICT産業の発展を、そのまま両モデルの優劣に読み替えることはできない。国や産業の成果には、需要、技術、市場構造、事業戦略など多くの要因が関わる。米国系自動車メーカーの経営危機や、リーン生産方式の国際的な普及が併存したことも、国籍だけで人事制度や競争力を説明できないことを示す。表1は理念型の比較であり、日米企業の実態を例外なく二分したものではない。

第一に、品質改善や工程間の調整が重要な製造現場では、技能形成と従業員参加は引き続き有効である。Arthur（1994）の米国ミニミルの研究でも、コミットメント型の人事システムと、良好な製造成果や低い離職率との関連が報告された。ただし、そのデータは1988～89年に収集されており、1990年代以降の変化を直接検証したものではない。特定産業の観察研究から、全産業での優越性や制度導入の因果効果を結論することもできない。

第二に、制度の有効性は、戦略、技術、仕事の相互依存性、必要技能によって異なる。改善や協働を多く必要とする仕事では広い裁量が役立つ一方、手順の遵守が品質や安全を左右する仕事では、標準化と確認も不可欠である。また、訓練には費用がかかり、需要の変動が大きい場合には雇用維持にも負担が生じる。企業と従業員の双方にとっての便益と費用を比較する必要がある。

第三に、雇用関係の多様化や企業再編を考えると、一企業への長期的な忠誠だけを前提にはできない。従業員は専門職、担当プロジェクト、顧客などにも強い関与を持ち得る。成長機会、公正な評価、働きがいを提供し、企業の目標と専門職としての目標を結びつけることもコミットメント形成の方法となる。正社員の安定を非正規雇用者に負担を移すことで支えていないか、参加が過重労働や同調圧力に変わっていないかも評価すべきである。

最後に、コントロールを組織の活動を目標に向けて調整することと広く捉えれば、価値の共有や自己管理も統制の仕組みに含まれる。したがって、細かな行動監視を弱めながら、目標、品質基準、相互確認を維持することは可能である。Waltonの議論は、管理の中心を監督から自発的協力へ移す提案として評価できるが、統制の全面廃止や唯一最善の制度への一律移行として理解すべきではない。

### 小問3

採用するのは、専門性と自律性を尊重する人事制度に、数千人規模の開発を支える明確な責任と共通基準を組み合わせた施策ミックスである。開発者の知識と創造性を引き出しつつ、チーム間の依存関係を調整する。

| 領域 | 採用する施策と狙い |
| --- | --- |
| 作業設計 | 開発、設計、品質保証などの職能を組み合わせた小規模チームを設け、担当製品の改善に継続的に責任を持たせる。具体的な実装方法は現場に委ねる。 |
| 業績評価 | 企業全体の方向と各チームの目標を結びつけ、顧客価値、品質、納期、協働、技術的貢献を評価する。コード行数など単一指標で個人を序列化しない。 |
| 管理組織 | 日常の判断はチームに委譲する。共通基盤や重大な設計変更は、専門家が参加する横断的な場で調整し、判断権限と相談先を明確にする。 |
| 賃金体系・キャリア | 現地の人材市場と専門能力を踏まえて報酬を設定し、個人の貢献とチームの成果の両方を反映する。管理職と技術専門職の双方に昇進経路を設ける。 |
| 雇用保障・訓練 | 現地採用を重視し、職務と期待役割を明示する。継続学習、社内公募、配置転換を支援し、短期的な人員削減に依存しない。実行できない終身雇用の約束は避ける。 |
| 労使関係・コミュニケーション | 事業の方向や変更理由を共有し、技術提案、振り返り、異議申し立ての機会を設ける。日本本社と現地拠点の間にも双方向の対話の仕組みを置く。 |
| 経営哲学 | 株主への説明責任を果たすとともに、顧客の信頼、従業員の成長と健康、長期的な技術蓄積を重視する。目先の成果だけで研究開発や育成を切り捨てない。 |
| 品質・情報管理 | レビュー、自動テスト、アクセス権限、機密情報の取扱基準を共通化する。重大なリスクは管理者へ報告し、必要な承認を得る。 |

この組み合わせでは、共通基準は裁量の境界を明確にし、その範囲内では本人が専門性を発揮できるようにする。例えば、顧客情報の保護基準は全員が守る一方、機能の実装方法はチームで決定する。統制の予測可能性と評価の公正さが信頼を支え、信頼が自発的な報告や協力を促すという補完関係をつくるのである。

導入後は、品質、開発の所要時間、顧客評価に加え、離職、学習機会、従業員の負担を確認する。会社への忠誠を一方的に要求するのではなく、専門職として成長できる環境と、組織として責任を果たせる仕組みを両立させる。
