## **Description**

### 原題に基づく要約（日本語）

[公式原題](https://sys.es.osaka-u.ac.jp/images/pdf/R4-1.pdf)

1. $x>0$ で $y=x^{x^x}$ を微分する。
2. 一辺 $1\,\mathrm{km}$ の正方形の4頂点に工場がある。交差点を設けることを許して道路で4工場を結ぶ。道路の幅を無視し、総延長の最小値を求める。
3. 直円錐の全表面積を一定とする。体積を最大にする高さと底面半径の比を求める。
4. 三角形 $ABC$ が単位円に外接し、辺 $AB,BC,CA$ の接点をそれぞれ $P,Q,R$、円の中心を $O$ とする。$\angle POQ=2x,\ \angle QOR=2y,\ 0<x,y<\pi/2$ と置く。(a) 面積を $x,y$ で表す。(b) 最小面積と、そのときの $x,y$ を求める。

### 题目描述

1. 对 $x>0$，求 $y=x^{x^x}$ 的导数。
2. 边长为 $1\,\mathrm{km}$ 的正方形四个顶点各有一家工厂。允许设置道路交汇点，忽略道路宽度，求连接四家工厂所需道路总长度的最小值。
3. 保持直圆锥的总表面积不变，求使其体积最大时高度与底面半径的比值。
4. 三角形 $ABC$ 外切于单位圆，边 $AB,BC,CA$ 的切点分别为 $P,Q,R$，圆心为 $O$。令 $\angle POQ=2x,\ \angle QOR=2y,\ 0<x,y<\pi/2$。用 $x,y$ 表示三角形面积，并求最小面积及相应的 $x,y$。

## **Kai**
### (1)
$z=x^x$ とおくと、

$$
\begin{aligned}
\log z &= x \log x
\\
\frac{1}{z} \frac{dz}{dx} &= \log x + 1
\\
\therefore \ \
\frac{dz}{dx}
&= z \left( \log x + 1 \right)
\\
&= x^x \left( \log x + 1 \right)
\end{aligned}
$$

であり、 $y=x^z$ であるから、

$$
\begin{aligned}
\log y &= z \log x
\\
\frac{1}{y} \frac{dy}{dx}
&= \frac{dz}{dx} \log x + \frac{z}{x}
\\
&= z \left( \log x + 1 \right) \log x + \frac{z}{x}
\\
&= x^{x-1} \left( x \left( \log x + 1 \right) \log x + 1 \right)
\\
\therefore \ \
\frac{dy}{dx}
&= y x^{x-1} \left( x \left( \log x + 1 \right) \log x + 1 \right)
\\
&= x^{x^x+x-1} \left( x \left( \log x + 1 \right) \log x + 1 \right)
\end{aligned}
$$

がわかる。

### (2)
正方形の頂点を $A=(0,1),B=(0,0),C=(1,0),D=(1,1)$ とし、単位を km とする。

最短網には閉路や不要な枝がなく、内部の分岐点では3本の直線が $120^\circ$ で交わる。角度がこれより小さければ分岐を少し移して短縮できる。正方形の頂点の内角は $90^\circ$ なので、最短網では各頂点の次数は1となり、内部の分岐点は2個である。交差する枝も短縮できるため、対角の頂点どうしを対にする形は除かれ、隣り合う2頂点ずつを結ぶ形を考えればよい。

対称性と距離の凸性から、分岐点を $S=(u,1/2),T=(1-u,1/2)$ と置ける。総延長は

$$\ell(u)=4\sqrt{u^2+1/4}+1-2u,\qquad0\le u\le1/2.$$

$\ell'(u)=4u/\sqrt{u^2+1/4}-2=0$ より $u=1/(2\sqrt3)$。$\ell''(u)>0$ なので

$$\boxed{\ell_{\min}=1+\sqrt3\ \mathrm{km}}.$$

![正方形の四頂点を二つの分岐点で結ぶ最短道路網。](https://raw.githubusercontent.com/Myyura/the_kai_project_assets/main/kakomonn/osaka_university/engineering_sciences/sys/2023/osaka-sys-2023-network.svg)

### (3)
底面半径を $r$、高さを $h$、固定された総表面積を $S$ とする。$q=\sqrt{r^2+h^2}/r>1$ と置くと

$$S=\pi r^2(1+q),\qquad V=\frac\pi3r^3\sqrt{q^2-1},\qquad V^2=\frac{S^3}{9\pi}\frac{q-1}{(q+1)^2}.$$

$$\frac d{dq}\frac{q-1}{(q+1)^2}=\frac{3-q}{(q+1)^3}$$

より最大値は $q=3$ のときであり、

$$\boxed{h/r=\sqrt{q^2-1}=2\sqrt2}.$$

### (4)
#### a)
残る接点間の中心角の半分を $z=\pi-x-y$ とすると、$0<z<\pi/2$、すなわち $\pi/2<x+y<\pi$。接線の長さは各頂点について $\tan x,\tan y,\tan z$ である。内接円の半径が1なので、面積は半周長に等しく、

$$\boxed{S(x,y)=\tan x+\tan y-\tan(x+y)}.$$

#### b)
停留条件は

$$\sec^2x=\sec^2y=\sec^2(x+y).$$

$x,y\in(0,\pi/2)$ より $x=y$ であり、上記の範囲内では $x=y=\pi/3$ となる。さらに $\tan$ は $(0,\pi/2)$ 上で厳密に凸なので、$x+y+z=\pi$ より

$$S=\tan x+\tan y+\tan z\ge3\tan(\pi/3)=3\sqrt3.$$

等号は $x=y=z=\pi/3$ のときに限る。よって

$$\boxed{x=y=\pi/3,\qquad S_{\min}=3\sqrt3}.$$
