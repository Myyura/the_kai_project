## 出题意图整理

除2026年度有官方说明外，下表均为依据题目要求、配点和易错限定所作的推断。

| 年度 | 主要考点 | 命题意图 |
|---:|---|---|
| 2015 | 重复码、最大似然/限界距离、IPv4路由汇总 | 区分“正解、误解、拒绝译码”三种概率，并检验能否按classful/CIDR规则最小化路由表。 |
| 2017 | Huffman扩展信源、传输层控制 | 检查是否把“每个符号对”的码长换算成“每个原始符号”，并能从RTT估计、窗口并行与RTO解释吞吐。 |
| 2018 | Hamming码、Ethernet | 要求从校验矩阵的列性质证明极限，而非只背结论；网络部分强调最小帧长与往返传播延迟。 |
| 2019 | dyadic概率前缀码、距离向量 | 要求给出归纳构造并逐轮同步更新，尤其识别旧距离互相引用造成的count-to-infinity。 |
| 2020 | 可靠数据传输、CRC | 通过协议1→3逐步暴露ACK损坏、重复交付与丢包问题，同时检验发送/传播/ACK时间是否全部计入。 |
| 2021 | CSMA/CD、级联BSC | 刻意区分首bit的单程传播与碰撞检测的往返传播，并要求真正证明级联后的对称性。 |
| 2022 | 有限路由表、唯一可译码 | 不只构造可达路由，还要求给出最坏路径的最优上下界；编码部分区分Kraft条件、前缀码与唯一可译码。 |
| 2023 | TCP AIMD吞吐模型 | 从窗口锯齿面积和损失周期推出经典 $1/\sqrt p$ 量级，而非只记忆公式。 |
| 2024 | CSMA、隐藏终端 | 检查有线载波侦听直觉为何不能直接解决无线互听不可见，并要求说清RTS/CTS的预约顺序。 |
| 2025 | HTTP over TCP | 贯通三次握手、URL、持久连接与流媒体，重点是跨层时延：首个keep-alive含双向各一次 $R$。 |
| 2026 | 距离向量与链路状态 | 官方意图为评价两类路由协议的动作特征、路由表更新、链路故障后的变化及其差异；题面还刻意保留并列下一跳，考查对算法定义边界的处理。 |

整体趋势是：2015–2022常将信息论编码与网络协议并列；2023以后集中于TCP、MAC、HTTP和路由协议本身。反复出现的评分点是“按题面定义精确计时”“逐轮写出状态”“给出最优性的下界和可达构造”，而不是只写协议名称。

## 民间答案逐年校勘

### 2015

- (1-1)～(1-3-1)正确；(1-3-2)缺失。约束下应选 $d=1$，正复号概率为0.91854。
- (2-1)六个选择正确。
- (2-2)把 `10.0.0.0/8` 与 `192.168.130.0/24` 的出口写成 #1；二者都连接在C侧，应从A的 #3 输出。
- (2-3)逐主机式 $9+H_B+H_C$ 正确；classful必须为 $5+N_B+N_C$，不能把多个Class C网络直接合并。民间答案未完成classless；利用最长前缀匹配，可令C侧 `192.*` 走 `/8`，再以B侧 `192.128.*`～`192.130.*` 的 `/14` 作为更具体的例外，加上 `10.*` 与 `172.16.*`，最少为4项，而不是把新增地址群机械地各算一个 `/16` 后得到7项。
- (2-4)缺失。

### 2016

附件中虽有标注为2016的答案页，但没有可核验原题，无法确认题号、条件和图形；按用户要求不反推、不生成题解。

### 2017

- 二次扩展的概率正确，但只画一棵树；同概率的 `ab`、`ba` 对调后还有另一棵。`1.56` 是每个二元符号对的平均长度，题目问每个原始符号，故应除以2得0.78。
- 扩展信源三空应为 $nH(S),1/n,1/\delta$；民间答案没有对应题面不等式。
- 流量控制中memory size漏答，拥塞的transmission latency与重传的loss写反。
- 停等吞吐结论正确；窗口图缺少DATA/ACK编号，无法验证窗口恒为3。
- RTO不能只取RTT平均值，还需RTT偏差形成安全余量，并在连续超时时退避。

### 2018

- Hamming填空与生成矩阵基本正确。
- (1-2)只写结论，缺少“$m$ 位非零且互异列最多 $2^m-1$ 个”的关键上界。
- (1-3)把固定检验矩阵说成“列不再互异”并不成立；真正原因是完备Hamming码把每个非零syndrome都解释为某个单比特错误。
- Ethernet最大距离计算误用了1 km，且漏比较往返传播时间；题给2.5 km时应比较25 μs与最小帧发送时间51.2 μs。
- 低混杂度下题目已令载波检测时间可忽略，两种方式应近似相同；不能据检测开销判Pure ALOHA更高。

### 2019

- 前缀码树、平均长度和熵正确；归纳证明的基例缺少 $m_1=m_2=1$ 及码字 `0,1`，归纳步完全缺失。
- 距离向量更新式只考虑一个邻居，缺少对全部相邻节点的候选距离取最小。
- 把 $D_y$ 写成 `[2,0,8]`，正确为 `[2,0,3]`，且漏写确认收敛的第二步。
- 断链后step 1仍使用z上一轮广告的旧距离2，因此 $d_y(x)$ 是 `3,3,5`，不是 `∞,3,5`。

### 2020

- 协议2的问题不是“NACK被当成ACK”，而是正确数据已交付、ACK损坏后同一数据被重传并再次交付。
- (1-3)最终25 packets/s正确，但过程把 $24/1600$ 错算为0.02 s，同时漏掉 $8/1600=0.005$ s的ACK发送时间；两个错误恰好抵消。完整周期为0.04 s。
- CRC填空中，次数为 $r$ 的生成多项式保证检测长度不超过 $r$ 的burst error，不是 $r-1$。
- CRC余数为0不能绝对证明无误；生成多项式倍数型错误不可检出。

### 2021

- 红笔修正后的carrier/jam、$L/V$ 与 $F_B\ge CL/V$ 正确；蓝笔把“首bit到达”误计入帧发送时间，并把同时发送时B检测碰撞误写成往返条件。
- 最大线长的核心不是一般衰减或成本，而是 $F_{\min}/C\ge2L_{\max}/V$，保证发送结束前能检测最远碰撞。
- 二进指数退避应在随冲突次数扩大的离散窗口中随机选槽，而不是固定等待 $2^iR$。
- 级联BSC的概率式正确，但“两个加数分别不大”不能推出其和不超过1/2；应使用 $(1-2\varepsilon_1)(1-2\varepsilon_2)\ge0$。只证明概率和为1也不足以证明对称性。

### 2022

- (1-1)只写新增项而未保留完整表；题目要求完整路由表。
- (1-2)第二条必须是“其他/default → IF#1”，只写精确目的地 $LN_2$ 无法保证其余网络可达。原题把路径长度定义为本地网络之间经过的全部链路，所以最大值是 $2n+2$，不是只算环内的 $2n$。
- (1-3)一般式错误。正确最优值为 $\max\{n,2n+2-k\}+2$；前一项是环直径下界，后一项来自最多 $k-2$ 条反方向个别路由，末尾 `+2` 是两端接入链路。
- 瞬时码 $C_2$ 正确；唯一可译码只有 $C_1,C_2$，例如 $C_4$ 有 `ad=bf=10001`。
- Kraft三空应为ウ、オ、キ；满足Kraft长度条件不代表“给定的这个码”必为前缀码。

### 2023

- (1) $W\,\mathrm{MSS}/R$、(2) timeout与3个duplicate ACK、(3-1) $\tau=W_LR/2$ 均正确。
- (3-2)、(3-3)缺失。题目给出的 $3W_L^2/8$ 对应窗口锯齿的连续/梯形面积近似；由 $3W_L^2/8=1/p$ 才能推出平均速率的 $1/\sqrt p$ 形式。

### 2024–2026

未提供民间答案，全部由原题独立推导。2025最易漏掉首个控制消息往返所含的两个 $R$，正确约束为 $0<S\le T-2R$。2026在 $i+2$ 轮时B经A、C到D的候选距离同为4，题面没有tie-break规则，因此下一跳两者均可；全体首次判D不可达为第 $i+M-1$ 轮。
