# 北海道大学 国際広報メディア・観光学院 国際広報メディア研究コース 2025年8月実施 日本語論述 問題1

【問題1】

これまで動物園は、生きた多様な動物を見ることができる場所として、行楽地や観光の目的地、あるいは児童の教育の場などとして多様な機能を担ってきた。しかし現在、娯楽の多様化あるいは本来の生息地で生きていくという動物の権利の観点から、動物園は時代遅れでいずれ消滅すべきものだという意見もある。あなたは動物園はこれからも存続すべきであると考えるか。それとも動物園がこれまで担っていた機能は、今後は別のかたち、別のメディアで代用されることができるのか。あなたの考えを述べなさい。

### 题目描述

2026年度前期。考试时间：10:00〜12:00（2小时）。答题纸共2张，每张25字×40行＝1000字。

从问题1〜4中选择1题，用1600〜2000字的日语横向书写作答。请在适当的位置换行分段。换行产生的空格也计入字数。

【问题1】

迄今为止，动物园作为能够看到多种活体动物的场所，一直承担着游乐场所、旅游目的地以及儿童教育场所等多种功能。然而，如今也有人从娱乐方式日益多样化，或动物有权在其原本的栖息地生活的角度出发，认为动物园已经过时，迟早应当消失。你认为动物园今后仍应继续存在吗？还是说，动物园迄今承担的功能今后可以通过其他形式、其他媒介来替代？请阐述你的看法。

## **Kai**

私は、動物園はこれからも存続すべきであると考える。その理由は、動物園が教育の場として重要な役割を果たしているだけでなく、研究や種の保存という社会的使命を担っており、それらの役割は映像やVRなどの新しいメディアによって完全に代替することはできないからである。

まず、動物園には教育施設として大きな意義がある。確かに近年では、高精細な映像やインターネット配信、VR技術などの発達によって、世界中の動物を自宅にいながら観察することが可能になった。そのため、「実際に動物園へ行かなくても十分ではないか」という考え方にも一定の説得力がある。

しかし、映像を通して動物を見ることと、生きた動物を実際に目の前で観察することとの間には、本質的な違いがある。例えば、動物の大きさや動き、鳴き声、におい、周囲の環境、さらには他の来園者とともに観察するという体験は、映像だけでは十分に伝えることができない。こうした身体的な経験を伴う学びは、単なる知識の習得ではなく、生命や自然環境への関心や理解を深める契機となる。

特に子どもたちにとって、このような体験には大きな教育的価値がある。教科書や映像でライオンやゾウについて学ぶことはできても、実際にその姿を目の当たりにしたときに受ける驚きや感動は、それらとは質的に異なる経験である。その経験が、動物への興味だけでなく、生物多様性や環境保全への関心へと発展していく可能性もある。近年重視されている体験型学習という観点から見ても、動物園は学校教育を補完する重要な役割を果たしていると言えるだろう。

もちろん、教育という役割だけであれば、今後さらに映像技術が発達することで、その一部は代替されていくかもしれない。しかし、それでもなお、生きた動物と直接向き合う経験そのものを完全に置き換えることは難しい。新しいメディアは動物園の役割を補完することはできても、それに完全に取って代わる存在にはなり得ないと考える。

さらに、動物園は教育施設であるだけではなく、研究機関として、また希少種の保存を担う施設としても重要な役割を果たしている。

近年、多くの野生動物が森林開発や気候変動などによって生息地を失い、絶滅の危機に瀕している。そのような状況の中で、動物園では希少種の繁殖や飼育技術の開発が進められ、種の保存に大きく貢献している。また、動物の行動や生態に関する研究は、野生動物の保護や生息環境の改善にも役立てられている。このような活動は一般にはあまり知られていないが、現代の動物園は単なる娯楽施設ではなく、教育・研究・保全という複数の役割を担う社会的な施設へと変化してきている。また、こうした活動は来園者が動物や自然環境への理解を深める契機ともなり、その成果は地域社会にも広く還元されている。このように教育・研究・保全が一体となって社会に果たしている役割も、映像やVRなどの新しいメディアだけでは十分に代替することは難しい。

もっとも、動物園に対しては、本来は野生で生活すべき動物を人工的な環境で飼育することは、動物の権利や福祉の観点から問題があるという批判も存在する。このような考え方は近年ますます重視されるようになっており、決して軽視すべきではない。実際に、狭い展示施設での飼育や、動物に過度なストレスを与える展示方法については改善すべき点も少なくないだろう。

しかし、そのことは直ちに動物園そのものを廃止すべきであるという結論には結び付かない。むしろ、動物福祉に十分配慮した飼育環境や展示方法へと改善を進めながら、教育・研究・種の保存という本来の役割をさらに充実させていくことが重要である。実際、近年では動物本来の行動を引き出す展示方法や、より自然に近い環境を再現した展示施設を導入する動物園も増えている。動物園は社会の価値観の変化に応じて、その在り方を見直しながら発展していくことが可能なのである。

以上のように、動物園は教育、研究、種の保存を通して社会に多面的な役割を果たしている。映像やVRなどの新しいメディアは、それらの役割を補完することはできても、完全に代替することは難しい。今後は動物福祉への配慮を一層進めながら、その社会的役割を発展させていくことが望ましい。つまり、存続か廃止かという二者択一ではなく、動物園の在り方そのものを改善していくという第三の方向性も考えられる。その意味で、動物園は時代遅れの施設ではなく、新しい時代に合わせて進化していくべき社会的な施設であると考える。
