図 1 はこの仕組みを図解したものである。新しい文字列 `word` が与えられ、関数 `calcKey(word)` の値が $i$ であるとき、`data[i][num[i]]` に `word` を代入している。

### 题目描述

给定函数 `calcKey(word)`，它把字符串映射为 $0,1,\ldots,N-1$ 中的整数；不同字符串可能取得同一个值。键值为 $i$ 的字符串保存在 `data[i]` 中，`num[i]` 表示该处当前已有的不同字符串数，同一个字符串不得重复保存。

1. 写出这种按函数返回值分散保存数据的方法名称。
2. 为节省二维数组中的空闲空间，写出适合替代每行数组的数据结构。
3. 说明 `calcKey` 应满足怎样的性质，才能防止插入和查找效率恶化。
4. 说明如何使插入与查找的计算量接近常数。
5. 补全 `register`：先检查同一字符串是否已经存在，若不存在则将其登记到正确位置。

## **Kai**

### (1)

この手法を

$$
\boxed{\text{ハッシュ法（hashing）}}
$$

という。`calcKey` はハッシュ関数、返り値はハッシュ値に相当する。

### (2)

各 `key` に対して必要な要素だけを保持できる

$$
\boxed{\text{連結リスト}}
$$

を用いるのが望ましい。この衝突処理法を分離連鎖法という。

### (3)

`calcKey` は、入力される文字列を $0,1,\ldots,N-1$ にできるだけ一様に分散させることが望ましい。特定の値に文字列が集中すると、その場所の要素を順に調べる時間が長くなる。また、ハッシュ値自体も短時間で計算できることが望ましい。

### (4)

格納する異なる文字列数を $M$ とし、負荷率を

$$
\alpha=\frac{M}{N}
$$

とする。十分大きい $N$ と一様な `calcKey` を用い、$M$ の増加に応じて表を拡張して再ハッシュすることで、$\alpha$ を一定以下に保つ。このとき各 `key` に属する要素数の期待値が一定に抑えられ、格納・検索はいずれも期待計算量 $O(1)$ となる。

### (5)

```c
void register(char* word) {
    int key = calcKey(word);
    int i;

    for (i = 0; i < num[key]; i++) {
        if (strcmp(data[key][i], word) == 0) {
            return;
        }
    }

    data[key][num[key]] = word;
    num[key]++;
}
```

既存の `num[key]` 個を調べ、一致すれば何もせず終了する。一致しなければ添字 `num[key]` の位置に追加し、要素数を 1 増やす。
