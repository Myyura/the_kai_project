# 東北大学 医工学研究科 医学系コース 2021年8月実施 数学基礎 問題1-3

## **Author**
[Miyake](https://miyake.github.io/exams/index.html), 祭音Myyura

## **Description**

### 題意の要約（暫定）

1. 次の極限を求めよ。
   1. $\displaystyle\lim_{x\to0}\frac{x^2}{1-\cos x}$
   2. $\displaystyle\lim_{x\to0^+}\frac{\sqrt{x}}{\log x}$
   3. $\displaystyle\lim_{x\to0^+}\frac{\tan^{-1}x}{\sqrt{x}}$
2. 次の不定積分を求めよ。
   1. $\displaystyle\int(6x-3)^5\,dx$
   2. $\displaystyle\int\frac{1}{\sqrt[3]{1-2x}}\,dx$
   3. $\displaystyle\int x^2\log x^2\,dx$
   4. $\displaystyle\int\frac{1}{3x^2+2x-1}\,dx$
3. 曲線 $y=2\sqrt{x}-x^2$ と直線 $y=x$ が囲む領域の面積を求めよ。

### 题目描述



1. 计算下列极限：
   1. $\displaystyle\lim_{x\to0}\frac{x^2}{1-\cos x}$；
   2. $\displaystyle\lim_{x\to0^+}\frac{\sqrt{x}}{\log x}$；
   3. $\displaystyle\lim_{x\to0^+}\frac{\tan^{-1}x}{\sqrt{x}}$。
2. 计算下列不定积分：
   1. $\displaystyle\int(6x-3)^5\,dx$；
   2. $\displaystyle\int\frac{1}{\sqrt[3]{1-2x}}\,dx$；
   3. $\displaystyle\int x^2\log x^2\,dx$；
   4. $\displaystyle\int\frac{1}{3x^2+2x-1}\,dx$。
3. 求曲线 $y=2\sqrt{x}-x^2$ 与直线 $y=x$ 所围成区域的面积。

## **Kai**
### 問題1
各極限は次のように求まる。

#### (1)

$$
\begin{aligned}
\lim_{x \to 0} \frac{x^2}{1 - \cos x}
&= \lim_{x \to 0} \frac{2x}{\sin x}
\\
&= \lim_{x \to 0} \frac{2}{\cos x}
\\
&= 2
\end{aligned}
$$

#### (2)

$0<x<e^{-1}$ では $\log x<-1$ なので、

$$
0\le\left|\frac{\sqrt{x}}{\log x}\right|
=\frac{\sqrt{x}}{|\log x|}
\le\sqrt{x}\longrightarrow0\qquad(x\to0^+).
$$

はさみうちの原理により、

$$
\lim_{x\to0^+}\frac{\sqrt{x}}{\log x}=0.
$$

#### (3)

$$
\begin{aligned}
\lim_{x \to 0^+} \frac{\tan^{-1} x}{\sqrt{x}}
&= \lim_{x \to 0^+} \frac{\frac{1}{x^2+1}}{\frac{1}{2} x^{-\frac{1}{2}}}
\\
&= 2 \lim_{x \to 0^+} \frac{\sqrt{x}}{x^2+1}
\\
&= 0
\end{aligned}
$$

### 問題2
#### (1)

$$
\begin{aligned}
\int (6x-3)^5 dx
&= 3^5 \int t^5 \frac{dt}{2}
\ \ \ \ \ \ \ \ (t=2x-1)
\\
&= \frac{3^5}{2 \cdot 6} t^6 + C
\ \ \ \ \ \ \ \ ( C \text{ は積分定数 } )
\\
&= \frac{81}{4} (2x-1)^6 + C
\ \ \ \ \ \ \ \ ( C \text{ は積分定数 } )
\end{aligned}
$$

#### (2)

$$
\begin{aligned}
\int \frac{1}{\sqrt[3]{1-2x}} dx
&= \int t^{- \frac{1}{3}} \frac{-dt}{2}
\ \ \ \ \ \ \ \ (t=1-2x)
\\
&= - \frac{1}{2} \cdot \frac{3}{2} t^\frac{2}{3} + C
\ \ \ \ \ \ \ \ ( C \text{ は積分定数 } )
\\
&= - \frac{3}{4} (1-2x)^\frac{2}{3} + C
\ \ \ \ \ \ \ \ ( C \text{ は積分定数 } )
\end{aligned}
$$

#### (3)

$$
\begin{aligned}
\int x^2 \log x^2 dx
&= \frac{1}{3} x^3 \log x^2 - \frac{1}{3} \int x^3 \cdot \frac{2x}{x^2} dx
\\
&= \frac{1}{3} x^3 \log x^2 - \frac{2}{3} \int x^2 dx
\\
&= \frac{1}{3} x^3 \log x^2 - \frac{2}{9} x^3 + C
\ \ \ \ \ \ \ \ ( C \text{ は積分定数 } )
\end{aligned}
$$

#### (4)

$$
\begin{aligned}
\int \frac{1}{3x^2+2x-1} dx
&= \int \frac{1}{(x+1)(3x-1)} dx
\\
&= \frac{1}{4} \int \left( - \frac{1}{x+1} + \frac{3}{3x-1} \right) dx
\\
&= \frac{1}{4} \int \left( - \frac{1}{x+1}
+ \frac{1}{x-\frac{1}{3}} \right) dx
\\
&= - \frac{1}{4} \log |x+1|
+ \frac{1}{4} \log \left| x - \frac{1}{3} \right| + C
\ \ \ \ \ \ \ \ ( C \text{ は積分定数 } )
\end{aligned}
$$

### 問題3
$t = \sqrt{x}$ として、

$$
\begin{aligned}
f(t)
&= \left( 2t - t^4 \right) - t^2
\\
&= - t^4 - t^2 + 2t
\\
&= -t(t-1) \left( t^2 + t + 2 \right)
\end{aligned}
$$

とおくと、 $f(t)=0$ となるのは $t=0,1$ のときであることがわかる。
$0 \leq t \leq 1$ では $t\geq0$, $t-1\leq0$, $t^2+t+2>0$ なので、
$f(t)\geq0$ である。
よって、求める面積は、

$$
\begin{aligned}
\int_0^1 \left( 2 \sqrt{x} - x^2 - x \right) dx
&= \left[ 2 \cdot \frac{2}{3} x^\frac{3}{2}
- \frac{x^3}{3} - \frac{x^2}{2} \right]_0^1
\\
&= \frac{1}{2}
\end{aligned}
$$

である。
