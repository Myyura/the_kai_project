**問題 III**

つぎの C 言語のプログラム（ファイル名を `ex1.c` とする）について以下の設問に答えよ。

プログラム中 4～7 行に定義された関数「`putNum(int x);`」は非負の整数 $x$ を 10 進数で表示する関数である。引数 $x$ の値が 10 未満であれば、5 行目で、数字「0」の文字コードと $x$ とを加算することで数字「0」から「9」までの文字コードを計算し、「`putchar('0'+x);`」関数を用いてその数字を表示する。10 以上であれば、6 行目で、まず `x/10` を再帰呼出しで表示してから、`x%10` を再帰呼出しで表示する。

なお、以下では、引数 $x$ や $w$ には必ず非負の値が与えられること、および、$w$ の値は $x$ を表示するのに必要な桁数以上であることを仮定してよい。また、プログラム修正後に行数が増加してもよい。

```text
 1 #include<stdio.h>
 2 #include<stdlib.h>
 3
 4 void putNum(int x){
 5   if(x<10)putchar('0'+x);
 6   else { putNum(x/10); putNum(x%10); }
 7 }
 8
 9 int main(){
10   int x=0;
11   for(int i=1;i<=100;i++) x=x+i;
12   putNum(x); putchar('\n');
13   return 0;
14 }
```

`ex1.c`

1. このプログラムをコンパイル・実行したときに表示される文字列（数字列）を記せ。

2. `ex1.c` の 4～7 行を修正し、非負の整数を 2 進数で表示する関数「`void putNum(int x){}`」を定義せよ。解答用紙には修正後の関数定義を記述せよ。また、修正後の `ex1.c` をコンパイル・実行させると表示される文字列を記せ。

**问题 III**

对上述 C 程序（文件名为 `ex1.c`）回答问题。

第 4～7 行定义的 `putNum(int x)` 用十进制显示非负整数 $x$。若 $x<10$，第 5 行将数字字符 '0' 的字符编码与 $x$ 相加，得到 '0' 至 '9' 中相应数字的编码，再用 `putchar('0'+x);` 显示该数字。若 $x\geq10$，第 6 行先递归显示 `x/10`，再递归显示 `x%10`。

可以假设参数 $x,w$ 均非负，且 $w$ 不小于表示 $x$ 所需的位数。修改后代码行数可以增加。原程序、行号与 ASCII 表见上方。

## **Kai**

### 1. 十進表示

ループ終了後の $x$ は $1+2+\cdots+100=100\cdot101/2=5050$。従って表示は

```text
5050
```

であり、末尾には改行が付く。

### 2. 二進表示

10 を 2 に置き換えればよい。

```c
void putNum(int x) {
    if (x < 2) putchar('0' + x);
    else {
        putNum(x / 2);
        putNum(x % 2);
    }
}
```

$5050=2^{12}+2^9+2^8+2^7+2^5+2^4+2^3+2^1$ より、出力は

```text
1001110111010
```

となる。$x=0$ でも基底の場合に '0' を 1 文字出力する。

### 3. 幅を指定した二進表示

桁数 $w$ を再帰の停止条件にする。

```c
void putNum(int x, int w) {
    if (w == 0) return;
    putNum(x / 2, w - 1);
    putchar('0' + x % 2);
}
```

上位 $w-1$ 桁を先に表示してから最下位ビットを表示する。途中で $x=0$ になっても、残りの桁数だけ '0' を出力する。問題文の $w$ に関する仮定により、有効桁は失われない。

5050 の二進表現は 13 桁なので、先頭に 7 個の '0' を補った

```text
00000001001110111010
```

が表示される。

### 4. 幅を指定した十六進表示

```c
void putNum(int x, int w) {
    if (w == 0) return;
    putNum(x / 16, w - 1);
    int d = x % 16;
    putchar(d < 10 ? '0' + d : 'A' + (d - 10));
}
```

ASCII 表では '0'～'9' と 'A'～'F' がそれぞれ連続しているため、この文字コード計算で正しい桁が得られる。

$5050=1\cdot16^3+3\cdot16^2+11\cdot16+10$ なので、5 桁での出力は

```text
013BA
```

である。各出力の末尾には `main` の `putchar('\n')` による改行が付く。
