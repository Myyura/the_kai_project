# 中央大学 理工学研究科 情報工学専攻 2026年度外国人入試 問題II

## **Author**

祭音Myyura (Based on [中央大学の公式解答例](https://www.chuo-u.ac.jp/uploads/2026/03/admission_gschool_exam_science_2026_08-02.pdf) refined with GPT 6 Astra)

## **Description**

以下のプログラム Sort は配列に格納された整数値のデータを再帰的に分割し，分割したデータの値の大小を比較しながら併合していくことでデータを昇順に整列するプログラムである。このプログラムは併合に副プログラム Merge を使用する。なお，それぞれのプログラムは擬似コードで記述されている。

```text
○Sort(整数型の配列：list, 整数型：num)
  整数型の配列：slist1, slist2
  整数型：i, num1, num2
  if (【①】)
    num1 ← num ÷ 2
    num2 ← 【②】
    i ← 0
    while (i < num1)
      slist1[i] ← list[i]
      i ← i + 1
    endwhile
    i ← 0
    while (i < num2)
      slist2[i] ← 【③】
      i ← i + 1
    endwhile
    Sort(slist1, num1)
    Sort(slist2, num2)
    Merge(slist1, num1, slist2, num2, list)
    【list の出力処理】
  endif
```

```text
○Merge(整数型の配列 slist1, 整数型：num1,
       整数型の配列 slist2, 整数型：num2,
       整数型の配列：list)
  整数型：i, j
  i ← 0
  j ← 0
  while (【④】)
    if (slist1[i] < slist2[j])
      list[i + j] ← slist1[i]
      i ← i + 1
    else
      list[i + j] ← slist2[j]
      j ← j + 1
    endif
  endwhile
  while (i < num1)
    list[【⑤】] ← slist1[i]
    i ← i + 1
  endwhile
  while (j < num2)
    list[【⑥】] ← slist2[j]
    j ← j + 1
  endwhile
```

1. プログラム中の空欄 ① から ⑥ に入れる正しい式を答えよ。
2. 手続き sort を以下の配列 list とその要素数 7 を引数として呼び出したとする。最初の呼び出しも含めて，手続き sort は何回呼び出されるか答えよ。

   ```text
   list の内容：{2, 8, 3, 5, 7, 4, 1}
   ```

3. 手続き sort 中の「list の出力処理」で list の内容を画面に出力する。例えば，list の内容が問2の時，`{2, 8, 3, 5, 7, 4, 1}` と出力される。問2の list とその要素数 7 を引数として sort を呼び出した際の出力の様子を答えよ。
4. 手続き sort に与える配列の要素数を $n$ としたときの時間計算量をオーダー表記で答えよ。

#### 题目描述

上述程序 Sort 将数组中保存的整数数据递归地分割，一边比较被分割的数据的大小一边将其合并，从而将数据按升序排列。该程序使用子程序 Merge 完成合并。两个程序均以伪代码写成，程序及空栏 ①～⑥ 如上。

伪代码中，`整数型` 表示整数类型，`整数型の配列` 表示整数数组，`list の出力処理` 表示输出 list 的处理。

## **Kai**

### 1. 空欄の式

| 空欄 | 解答 |
| --- | --- |
| ① | `num > 1` |
| ② | `num - num1` |
| ③ | `list[num1 + i]` |
| ④ | `(i < num1) and (j < num2)` |
| ⑤ | `i + j`（または `i + num2`） |
| ⑥ | `i + j`（または `j + num1`） |

1 要素の配列は既に整列済みなので，①で再帰を止める。整数の除算 `num ÷ 2` によって前半の要素数を $\lfloor\texttt{num}/2\rfloor$ とし，②で残りを後半に割り当てる。後半の先頭添字は `num1` なので，③は `list[num1 + i]` となる。

Merge では，`i` と `j` はそれぞれ前半・後半から取り出した要素数である。両方に未処理要素がある間だけ先頭同士を比較するので，④には論理積を用いる。書き込み済み要素数は常に `i + j` であるから，⑤，⑥にもこの値を使える。

⑤のループが実行されるときは後半を使い切って `j = num2`，⑥のループが実行されるときは前半を使い切って `i = num1` である。そのため表の別解も等価である。

### 2. 呼び出し回数

呼び出し時の配列を実行順に並べると，次の 13 個である。

```text
 1. {2, 8, 3, 5, 7, 4, 1}
 2. {2, 8, 3}
 3. {2}
 4. {8, 3}
 5. {8}
 6. {3}
 7. {5, 7, 4, 1}
 8. {5, 7}
 9. {5}
10. {7}
11. {4, 1}
12. {4}
13. {1}
```

したがって答えは **13 回**。別の数え方として，1 要素の呼び出しを葉とする再帰木は，葉が 7 個で各内部節点が 2 個の子をもつ。内部節点は $7-1=6$ 個なので，総数は $7+6=13$ 個となる。

### 3. 出力の順序

出力は Merge の直後にだけ行われ，1 要素の呼び出しでは行われない。左部分列，右部分列，両者の併合結果という順序になるので，画面への出力は次の通りである。

```text
{3, 8}
{2, 3, 8}
{5, 7}
{1, 4}
{1, 4, 5, 7}
{1, 2, 3, 4, 5, 7, 8}
```

### 4. 時間計算量

分割時のコピーと併合には，合わせて要素数に比例する時間がかかる。出力処理を数える場合も，その呼び出しで出力する要素数に比例するため，同じオーダーに収まる。したがって，

$$
T(n)=T(\lfloor n/2\rfloor)+T(\lceil n/2\rceil)+\Theta(n),
\qquad T(1)=\Theta(1).
$$

再帰木の深さは $\Theta(\log n)$ で，各深さで処理する要素数の合計は $O(n)$ となる。よって求める時間計算量は

$$
\boxed{O(n\log n)}
$$

であり，この実装ではより厳密に $\Theta(n\log n)$ である。
